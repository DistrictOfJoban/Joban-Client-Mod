# JCM v2.2.3 for MTR 4.0.5 has been released!

Another minor client-only release to fix issues caused by scripting.  
Players using **v2.2.2** are strongly advised to update to this version, since previous versions may cause a clien crash.

## Additions
- Add `VanillaText.clickToCopyText()`, `VanillaText.clickToOpenURL()` and `VanillaText.withHoverText()` for more text customizations.

## Fixes
- Fix an accidental line sneaked into v2.2.2 causing a client crash.
- Fix scripted trains opening nearby PSD/APG for the entire carriage even without a nearby doorway.
